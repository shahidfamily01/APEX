# Apex Fit Club 🏋️‍♂️

A modern, responsive gym management and member portal for **Apex Fit Club**. Built with a focus on speed, accessibility, and user experience, this platform provides separate, privacy-focused environments for Gents and Ladies.

**Live App:** [https://gym-central-gateway.lovable.app](https://gym-central-gateway.lovable.app)

## ✨ Key Features

- **Gender-Specific Portals:** A dedicated entry gate that routes users to separate, tailored experiences (Gents/Ladies) to respect member privacy.
- **Trainer Profiles:** Detailed cards for head trainer Najam Ali Tariq and the rest of the professional team, featuring direct WhatsApp integration for easy communication.
- **Membership Plans:** Clear and concise pricing tables for strength training, cardio, and combined packages, alongside special promotional offers.
- **Live Member Counter:** Real-time counter showcasing community growth.
- **Responsive Design:** A fully responsive UI that looks great on mobile, tablet, and desktop devices.
- **Secure Registration:** Built-in form handling for safely onboarding new members.

## 🛠 Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Build Tool:** Vite
- **Development Platform:** [Lovable](https://lovable.dev)

## 🚀 Getting Started

To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed on your machine.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shahidfamily01/APEX.git
   cd APEX
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
